## 项目说明
<!--node {"id":"ex-info","type":"info"}-->

研究问题：一维热传导方程的显式有限差分解，网格加密时误差是否按二阶下降。这是一个小型数值验证，用来演示怎样记录方法、数据、结果和后来的更正。

- 合作方与分工：虚构的 A 组写求解器，B 组复核误差定义；本项目只做收敛性测试。
- 主要资料：脚本 `workspace/projects/example-project/analysis/convergence.mjs`；结果表 `workspace/projects/example-project/data/processed/convergence.csv`。
- 运行方法：`node workspace/projects/example-project/analysis/convergence.mjs`，在 `data/processed/` 重新生成结果表。

### 要回答的问题
<!--node {"id":"ex-l-question","kind":"info"}-->

显式格式在 r = dt/h² ≤ 0.5 时稳定，空间二阶、时间一阶；取 r 固定时总误差应随 h² 下降。要确认的是实际网格上观察到的阶数。

- 当前读数：N = 8 到 64 的最大误差按 1.65、1.82、2.00 的阶数下降，趋近二阶（T-20261002-01）。
- 受限于：只测了四个网格，粗网格的阶数偏低，原因按现有数据还分不出是离散误差的高阶项还是时间步取整（见 T-20261003-01）。

### Methods：误差与阶数的定义
<!--node {"id":"ex-l-methods","kind":"info"}-->

给后来接手的人用的约定，不是论文写作稿。

- 精确解 u(x,t) = exp(−t)·sin(x)，区间 [0, π]，终止时刻 t = 0.1，两端 u = 0。
- 误差：所有网格点上数值解与精确解之差的最大绝对值（max_error）。
- 观察阶数：相邻两个网格 p = log(e_N / e_2N) / log 2，N 是区间等分数。
- 时间步：取 dt 使 r 不超过 0.4，再按终止时刻取整步数，所以各网格的 r 略有差别（0.32 到 0.40，记在结果表里）。
